# Qissa

Cerita pendek interaktif berbentuk chat untuk Muslim Indonesia usia 17–40. Pembaca memilih; dalilnya datang setelahnya.

Mulai dari `CLAUDE.md` untuk peta repo dan aturan, lalu `docs/PRD.md`, `docs/SRS.md`, dan `docs/ARCHITECTURE.md`. Tugas pertama ada di `docs/BACKLOG.md`. Naskah ada di `content/episodes`, implementasi rujukan di `infra/prototype/index.html`, dan cara deploy di `infra/easypanel.md`.
